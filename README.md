# wca-ai-tool-s12--Clinical_assistant-


      CLINICAL FAQ ASSISTANT.

Project description .

The clinical FAQ Assistant is a python-based chatbot that uses Gemini API to answer frequently asked question for Healthclinic.
Acts as a virtual receptionists .


What the tool does:
 
Is it allows users to asks questions like location of the clinic, opening hours, services provided etc and  get information provided in the project give responses and creates a session summary and a saved conversation history so that the user can retrieve it later.

How to run the tool:

1. Clone the github repository to the computer.
2. Open the project folder in VSCode.
3. open terminal in VSCode.
4.install the required dependencies and run 
pip install -r requirements.txt

5. Set up your Gemini API key as explained below.
6. Run the application using 
python main.py
7. Follow menu instructions displayed in the terminal.


How to set the API KEY:
1.open Google AI Studio and obtain an API KEY buy selecting create new key.
2. In the main project folder create a .env file.
3.open the .env file and add the line;
GEMINI_API_KEY=your_api_key
3. Replace your_api_key with the real one that you copied form google ai studio.
4.Save the file.

KEEP THE API KEY PRIVATE. DO NOT SHARE OR UPLOAD TO GITHUB.
